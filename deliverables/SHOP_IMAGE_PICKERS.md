# 상품·12간지 이미지 선택 UI

## 목적

- 상품 구매 화면에서 상품과 12간지 디자인을 텍스트 셀렉트박스가 아닌 이미지로 쉽게 구분해 선택한다.
- 관리자에서 관리하는 상품명, 가격, 상세페이지 및 기존 주문 데이터 연결은 그대로 유지한다.

## 이미지 자산

- 원본: `reference/icon`
- 운영 자산: `public/assets/shop-icons`
- 상품 7종: 스티커, 팔찌, 목걸이, 키링, 팔찌&목걸이, 목걸이&키링, 팔찌&목걸이&키링
- 디자인 12종: 쥐, 소, 호랑이, 토끼, 용, 뱀, 말, 양, 원숭이, 닭, 개, 돼지

## 사용자 흐름

1. 상품 선택 행을 누르면 상품 이미지가 4열 그리드로 열린다.
2. 상품 이미지를 누르면 기존 상품 ID가 선택되고 그 상품에 연결된 디자인 목록이 갱신된다.
3. 디자인 선택 행을 누르면 12간지 이미지가 4열 그리드로 열린다.
4. 디자인 이미지를 누르면 기존 디자인 ID와 가격이 선택된다.
5. 선택된 항목에는 초록색 테두리와 체크 표시가 나타난다.
6. 닫기 버튼, 바깥 영역 터치, Esc 키로 선택 목록을 닫을 수 있다.

## 데이터 연결

- 상품 이미지는 상품 `slug`에 연결한다.
- 디자인 이미지는 디자인 이름에 연결한다.
- 선택 후 서버로 전달되는 `productId`, `designId`, `designIndex` 형식은 변경하지 않는다.
- 관리자가 설정한 상품명, 가격, 상세페이지와 디자인별 가격은 기존 데이터베이스 값을 계속 사용한다.

## 검증 기준

- 상품 7개와 디자인 12개 이미지가 누락 없이 표시되어야 한다.
- 이미지 선택 후 선택 행, 상품 요약, 단가와 결제예정금액이 같은 항목을 표시해야 한다.
- 모바일 화면에서 4열 이미지와 체크 표시가 겹치거나 잘리지 않아야 한다.
- 키보드와 스크린리더에서 선택 목록과 현재 선택 상태를 확인할 수 있어야 한다.
