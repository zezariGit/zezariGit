# REAL_QR_FIND 개인정보처리방침 페이지

## 1. 산출물 목적

- 기존 제자리 개인정보처리방침의 구성과 현재 REAL_QR_FIND 구현을 대조해 사용자용 개인정보처리방침을 제공한다.
- 로그인 전후 사용자 메인 화면 하단에서 정책 문서에 접근할 수 있게 한다.
- 공개 QR 페이지, 위치공유, 안심번호, 결제, 푸시 알림, 광고 등 현재 서비스의 개인정보 흐름을 한 문서에서 안내한다.

## 2. 구현 위치

- 정책 페이지: `/privacy`
- 사용자 메인 하단 링크: `개인정보취급방침`
- 페이지 소스: `app/privacy/page.js`
- 공통 링크 컴포넌트: `app/user-policy-footer.js`
- 스타일: `app/globals.css`

## 3. 문서 구성

1. 개인정보의 처리 목적과 항목
2. 보유기간과 파기
3. 공개 QR 페이지 및 제3자 제공
4. 처리위탁과 외부 서비스
5. 위치정보 처리
6. 이용자와 법정대리인의 권리
7. 아동 및 관리대상 개인정보
8. 쿠키와 자동수집 정보
9. 개인정보의 안전성 확보조치
10. 개인정보 보호책임자와 문의
11. 개인정보 권익침해 구제
12. 개인정보처리방침 변경

## 4. 현재 서비스 반영사항

- SNS 로그인 제공자를 Google, Kakao, Naver, Facebook으로 표시했다.
- 공개 QR 페이지에는 관리대상의 공개 정보와 050 안심번호만 제공하며 보호자 이름, 이메일, 주소, 원전화번호는 공개하지 않는다고 명시했다.
- 발견자가 `위치공유`를 직접 실행하고 브라우저 권한을 허용한 경우에만 위도, 경도, 정확도를 처리한다고 명시했다.
- Toss Payments, Bizcall, SMS 발송사, Meta Marketing API, Web Push 등 외부 처리 흐름을 안내했다.
- 결제 카드 원문 정보는 서비스 DB에 직접 저장하지 않고 결제대행사의 식별·승인정보를 저장하는 구조를 안내했다.
- 휴대전화 인증번호, 비밀번호 및 인증 토큰은 해시 처리하는 보안 원칙을 포함했다.

## 5. 사용자 화면 규칙

- 로그인 전 온보딩·로그인 화면과 로그인 후 대시보드 모두 페이지 최하단에 같은 링크를 표시한다.
- 정책 페이지는 프로젝트의 `gov-style.css` 색상·간격 토큰을 사용한다.
- 모바일에서는 목차 열 수를 줄이고, 데이터 표는 가로 스크롤로 읽을 수 있게 한다.
- 정책 페이지 상단의 이전 버튼으로 사용자 메인에 돌아갈 수 있다.

## 6. 운영 및 갱신 기준

- 수집 항목, 공개 범위, 외부 제공사, 보유기간 또는 회사 연락처가 변경되면 이 페이지를 함께 갱신한다.
- 개인정보 관련 기능 변경 시 `logs/DEV_HANDOFF_LOG.md`와 `logs/PRESENTATION_PROGRESS_LOG.md`에도 변경 이력을 누적한다.
- 본 문서는 현재 구현을 기준으로 작성한 운영 문서다. 정식 서비스 약관으로 확정하기 전 개인정보 보호 및 전자상거래 관련 법률 검토를 권장한다.
