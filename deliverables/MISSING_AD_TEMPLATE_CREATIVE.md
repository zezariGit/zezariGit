# REAL_QR_FIND 실종광고 양식 기반 소재

## 목적

보호자가 설정한 실종광고 정보를 `reference/실종광고 양식.png`의 고정 디자인에 합성해 Meta 광고 소재로 사용한다. 운영 화면의 크기나 휴대폰 해상도와 관계없이 동일한 결과를 만들기 위해 DOM 캡처 대신 Canvas 합성을 사용한다.

## 입력 데이터

- 왼쪽 사진 영역: 관리대상 대표 사진
- 오른쪽 정보 영역: 관리대상 이름, 만 나이, 성별
- 노란색 안내 영역: 관리대상별 보호자 메시지
- 하단 QR 영역: 해당 관리대상 공개 페이지로 연결되는 QR 코드

사진이나 QR이 없을 때는 빈 영역이 깨지지 않도록 대체 문구를 표시하며, 이름과 메시지가 길면 지정된 영역 안에서 글자 크기와 줄 수를 자동 조절한다.
보호자 메시지에 `010` 등 휴대폰 원번호가 포함되어 있으면 광고 이미지와 Meta 본문에서는 QR 연락 안내로 치환해 안심번호 정책을 우회한 개인정보 노출을 막는다.

## 생성 규격

- 원본 양식: `public/assets/missing-ad-template.png`
- 결과 크기: 1080 x 1350px, 4:5 비율
- 결과 형식: JPEG, 품질 0.92
- 사용자 미리보기와 최종 합성 이미지는 같은 배치 좌표를 사용한다.
- 최종 이미지는 결제 요청에 저장되고, 결제 완료 후 Meta 이미지 업로드 및 광고 소재 생성에 사용된다.
- Meta 광고의 클릭 목적지는 이미지 속 QR과 동일한 관리대상 공개 페이지다.

## 좌표 기준

| 항목 | 좌표/크기 |
| --- | --- |
| 대상자 사진 | x 36, y 396, 462 x 558 |
| 이름 | x 765, 중심 y 431, 최대 폭 270 |
| 나이 | x 765, 중심 y 575, 최대 폭 270 |
| 성별 | x 765, 중심 y 719, 최대 폭 270 |
| 보호자 메시지 | x 660, y 842, 최대 350 x 154 |
| QR 코드 | x 66, y 1087, 220 x 220 |

## 운영 확인 절차

1. 보호자 화면에서 관리대상과 광고 거리 및 기간을 선택한다.
2. 요약 화면의 광고 미리보기에서 사진, 이름, 나이, 성별, 보호자 메시지, QR 배치를 확인한다.
3. 결제를 완료하거나 관리자 계정의 결제패스를 사용한다.
4. 결제 완료 후 자동 Meta 발행 상태와 광고 피드 링크를 확인한다.
5. 시험 광고는 최소 거리와 최소 기간으로 생성하고 확인 직후 일시정지한다.

## 개인정보 및 보안

- 광고 이미지에는 보호자 이름, 전화번호, 이메일, 주소를 넣지 않는다.
- 보호자 메시지의 휴대폰 번호는 `보호자 연락은 QR을 이용해 주세요`로 자동 치환한다.
- QR은 활성화된 관리대상의 공개 페이지로만 연결한다.
- Meta 접근 토큰, 앱 시크릿, 결제 키는 이미지와 문서에 기록하지 않는다.
