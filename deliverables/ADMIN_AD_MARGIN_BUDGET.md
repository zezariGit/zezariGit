# 광고 결제 마진율 기반 Meta 예산

Project: REAL_QR_FIND / zezari

## 목적
- 보호자가 결제한 광고 상품 금액에서 관리자가 설정한 서비스 마진을 제외한 금액을 Meta 전체 기간 예산으로 편성한다.
- 관리자 설정 변경이 이미 결제되거나 집행 중인 광고 예산에 소급되지 않게 광고별 마진율을 저장한다.

## 관리자 설정
- 위치: `/admin?section=ad-pricing`
- 항목: `서비스 마진율`
- 허용 범위: 정수 0%~90%
- 기본값: 4%
- 거리·기간 옵션과 함께 저장하며 새 광고 신청부터 적용한다.

## 계산식
```text
보호자 결제금액 = 선택한 기간 금액 + 거리 추가금액
서비스 마진 = 보호자 결제금액 × 마진율
Meta 전체 기간 예산 = floor(보호자 결제금액 × (100 - 마진율) / 100)
Meta 일평균 예산 = floor(Meta 전체 기간 예산 / 광고 일수)
```

예시:
- 결제금액 70,000원, 마진율 4%: 서비스 마진 2,800원, Meta 예산 67,200원
- 결제금액 70,000원, 마진율 20%: 서비스 마진 14,000원, Meta 예산 56,000원

## 데이터
- `ad_settings.meta_margin_percent`: 현재 관리자 기본 마진율
- `subject_ads.meta_margin_percent`: 광고 신청 당시 마진율 스냅샷
- `subject_ads.meta_budget_amount`: Meta에 전달하는 전체 기간 예산
- `subject_ads.meta_daily_budget`: 관리자 조회용 일평균 예산
- `subject_ads.meta_budget_version = 3`: 마진율 기반 신규 예산 방식

기존 버전 1·2 광고는 저장된 예산을 그대로 사용한다. 운영 중 광고의 Meta 예산과 결제 기록은 자동 변경하지 않는다.

## 화면 반영
- 관리자 광고결제 관리: 마진율 입력, 70,000원 기준 계산 예시, 비소급 안내
- 보호자 광고 미리보기: 예상 Meta 집행예산과 적용 마진율
- 보호자 광고 결제: 결제금액, Meta 집행예산, 서비스 마진
- 관리자 광고 상세 및 CSV: 광고별 저장 마진율

## 검증
- 70,000원/4% 계산 결과 67,200원 확인
- 70,000원/20% 계산 결과 56,000원 확인
- 격리 DB에서 스키마 버전 33, 기본 마진율 4, 광고별 마진율 컬럼 생성 확인
- Next.js production build 통과
