# 온보딩·QR 관리·활성화 UI 정리 산출물

## 적용 범위

- 로그인 전 서비스 소개: 이전/다음 버튼 제거, 가운데 `로그인하기` 버튼 단일화
- 로그인 화면 및 미배정 QR 가입 화면: Facebook 버튼 제거
- 관리자 QR 관리: 별도 활성/미활성 필터·목록 열·상세 배지 제거
- 상품 수령 후 QR 활성화: 대상자 사진을 위에, 이름·생년월일·안내를 아래에 배치하는 세로형 카드 적용

## 동작 기준

- 서비스 소개는 좌우 스와이프와 페이지 점으로 3개 화면을 계속 탐색할 수 있다.
- `로그인하기`를 누르면 현재 소개 페이지와 관계없이 로그인 화면으로 이동한다.
- QR 관리의 대표 상태는 `사용중`, `미사용`, `스토어 선점`을 중심으로 한 개만 표시한다.
- 기존 Facebook 계정 데이터와 서버 인증 공급자 설정은 호환성을 위해 유지하되 사용자 로그인 버튼만 숨긴다.
- QR 활성화 처리와 관리자 QR 활성/비활성 제어 기능은 변경하지 않는다.

## 검증 항목

- Next.js 운영 빌드
- 보안 회귀 검사
- QR 선점 가입 회귀 검사
- SNS 계정 연결 회귀 검사
- 로그인 전 온보딩과 로그인 공급자 브라우저 확인
