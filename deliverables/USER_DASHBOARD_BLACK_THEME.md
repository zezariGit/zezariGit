# 사용자 대시보드 검정색 테마 및 탐색 구조 개편

## 요구사항

- 사전 승인된 검정색 CSS 시안을 실제 서비스 공통 스타일에 적용한다.
- 사용자 대시보드 상단의 `대시보드`, `보호자정보`, `관리대상정보` 탭을 제거한다.
- 현재 상태에서 관리대상을 한 화면에 최대 3명 표시한다.
- 4번째 대상부터 현재 상태 영역 안에서 가로 스와이프로 확인한다.
- 마지막 관리대상 아래에 `+` 버튼을 배치하고 관리대상정보 화면으로 연결한다.
- 보호자정보 수정은 마이페이지 팝업의 `정보 수정` 링크로 진입한다.
- 검은색 상단 앱 바와 브랜드 문구를 제거하고 알림은 왼쪽 위, 마이페이지는 오른쪽 위에 배치한다.
- 세 개의 빠른 메뉴 버튼은 모두 같은 흰색 배경과 검은색 테두리로 표시한다.
- 관리대상 스와이프 페이지 수와 현재 위치를 점으로 표시한다.
- 보호자별 관리대상 4명 제한을 제거하고 계속 등록할 수 있게 한다.

## 구현 내용

### 공통 검정색 테마

- `css/gov-style.css`의 기본 색상 토큰을 검정, 흰색, 중성 회색으로 변경했다.
- 성공, 주의, 위험 상태 색상은 의미 전달을 위해 기존 녹색, 주황, 빨강 계열을 유지했다.
- 브라우저와 설치형 PWA의 테마 색상을 `#111111`로 변경했다.
- 검은색 앱 헤더와 브랜드 마크는 후속 검토에 따라 제거했다.
- 알림 아이콘은 대시보드 왼쪽 위, 마이페이지 아이콘은 오른쪽 위에 독립적으로 배치했다.

### 대시보드 탐색

- 상단 3개 탭은 화면에서 제거했다.
- 숨겨진 편집 경로는 기존 저장 기능과의 호환을 위해 유지한다.
  - 보호자정보: `/?tab=guardian#guardian-info`
  - 관리대상정보: `/?tab=subjects#subjects-info`
- 편집 화면에는 `대시보드로 돌아가기` 링크를 제공한다.
- 마이페이지의 보호자정보와 대상자정보 `정보 수정` 링크가 위 경로를 사용한다.

### 현재 상태 가로 스와이프

- 관리대상을 3명 단위로 묶어 가로 스크롤 페이지로 렌더링한다.
- 마우스, 트랙패드, 모바일 터치 스와이프를 지원한다.
- 각 묶음은 `scroll-snap`으로 화면 시작점에 맞춰 정렬된다.
- 페이지 수만큼 원형 점을 표시하고, 현재 페이지 점을 더 진하게 표시한다.
- 점을 누르면 해당 페이지로 부드럽게 이동한다.
- 마지막 묶음 아래에는 등록 인원과 관계없이 원형 `+` 버튼을 표시한다.
- `+` 버튼은 관리대상 등록 및 수정 화면으로 이동한다.

### 관리대상 계속 등록

- 관리대상정보 화면의 최대 4명 안내와 `/4명` 카운터를 제거했다.
- 기존 관리대상 목록 마지막에 항상 빈 등록 양식 하나를 제공한다.
- 서버 저장 함수의 4명 제한 검사를 제거해 다섯 번째 이후 관리대상도 실제 DB에 저장할 수 있다.
- 관리자 역할 화면의 관리대상 수 표기도 최대치 없는 현재 인원으로 변경했다.

## 영향 범위

- DB 스키마는 변경하지 않았으며 관리대상 저장 개수 제한만 제거했다.
- 보호자정보 및 관리대상정보 서버 액션은 기존 구현을 그대로 사용한다.
- 기존 광고, 실종신고, 상품구매, 마이페이지 이동 기능을 유지한다.
