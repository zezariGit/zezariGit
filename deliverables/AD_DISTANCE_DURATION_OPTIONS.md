# 광고 거리·기간 선택형 설정

## 요구사항

- 보호자가 관리대상을 선택한 뒤 지도와 시작·종료일을 직접 입력하던 방식을 변경한다.
- 광고 노출 거리와 오늘부터의 광고 일수를 순서대로 선택한다.
- 선택을 마치면 대상자, 거리, 기간, 노출 안내와 결제금액을 한 화면에서 확인한다.
- 관리자는 광고결제 관리에서 거리와 기간 옵션을 각각 그리드로 추가·수정·삭제한다.
- 관리자가 저장한 활성 옵션은 보호자 화면에 바로 반영한다.

## 사용자 흐름

1. 온라인 실종신고에서 관리대상을 선택한다.
2. 광고 노출 거리를 선택한다.
3. 반경형 옵션은 휴대폰 현재 위치 권한을 요청하고 해당 좌표를 광고 중심점으로 사용한다.
4. 전국 확산 옵션은 위치 권한 없이 대한민국 전체를 대상으로 사용한다.
5. 오늘부터 진행할 광고 기간을 선택한다.
6. 대상자, 거리, 기간, 예상 범위, 날짜, 기간 금액, 거리 추가금액과 총액을 확인한다.
7. 기존 광고 소재 미리보기를 이미지로 생성한 후 Toss 광고 결제 화면으로 이동한다.

## 결제 및 Meta 처리

- 보호자 결제금액은 `기간 옵션 금액 + 거리 옵션 추가금액`으로 계산한다.
- 서버는 결제 준비 시 저장된 기간·거리 금액 스냅샷의 합계와 결제금액을 다시 검증한다.
- Meta 집행예산은 보호자 결제금액과 분리된 기존 예산 설정으로 계산한다.
- 반경형 옵션은 현재 위치의 위도·경도와 반경을 Meta 맞춤 위치 타겟에 사용한다.
- 전국 확산은 Meta 대한민국 국가 타겟을 사용한다.
- 기존 광고 데이터와 결제는 변경하지 않으며 새 방식은 `pricing_version = 3`으로 구분한다.

## DB 변경

- `ad_distance_options`: 거리, 범위 유형, 안내, 추가금액, 정렬, 노출 여부
- `ad_duration_options`: 일수, 안내, 기간금액, 정렬, 노출 여부
- `subject_ads`: 선택 옵션 ID·표시명과 범위 유형 스냅샷
- DB 스키마 버전: `29`

## 검증

- `npm run build`: 성공
- `git diff --check`: 공백 오류 없음
- 신규 `subject_ads` INSERT SQL 자리표시자 30개와 인수 30개 일치 확인
- 실제 Toss 결제와 신규 Meta 광고 발행은 비용 발생을 막기 위해 자동 테스트에서 실행하지 않는다.

## 저장영역 정렬 보완

- 관리자 저장영역은 안내문과 저장 버튼을 명시적인 2열 그리드로 배치한다.
- 데스크톱 저장 버튼 폭은 220~320px로 유지하고 안내문은 한국어 단어 단위로 줄바꿈한다.
- 좁은 화면에서는 안내문과 버튼을 한 열로 쌓고 버튼은 사용 가능한 폭을 채운다.
