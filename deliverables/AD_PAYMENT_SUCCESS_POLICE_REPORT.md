# 온라인 광고 결제 완료 화면 개편 및 112 경찰 신고 연계

Last updated: 2026-09-11 KST

## 1. 개요
보호자가 온라인 실종 광고 결제를 완료했을 때, 제공된 확정 그래픽 이미지를 표시하고 즉시 112 경찰 신고로 연결할 수 있는 연계 UI 및 통화 발신 기능을 제공한다.

## 2. 화면 구성 및 사용자 흐름
1. **광고 결제 완료 그래픽**:
   - `public/assets/ads/ad-payment-complete.png` 원본 이미지를 상단에 표시.
   - "광고 결제 완료", 녹색 체크 아이콘, "광고 결제가 완료되었습니다.", "광고는 Meta에서 광고 검토가 완료된 후 게재됩니다." 문구가 포함됨.
2. **경찰 신고 연계 섹션**:
   - **제목**: `경찰 신고도 함께 진행하시겠어요?` (밑줄 스타일, 클릭 시 112 확인 팝업 호출)
   - **설명**: `경찰 신고가 필요한 경우 112로 연결해 드립니다.`
   - **버튼**:
     - **[ 예 ]**: 녹색 버튼, 클릭 시 112 확인 팝업 모달 오픈
     - **[ 아니오 ]**: 흰색 바탕 녹색 외곽선 버튼, 클릭 시 광고 대시보드(`/account/ads`)로 이동
3. **112 전화걸기 확인 팝업 모달**:
   - 중앙 모달 및 배경 딤(Dark overlay) 처리 (ESC 및 외부 영역 클릭 시 닫힘)
   - 상단 연녹색 원형 안의 녹색 수화기 아이콘
   - **제목**: `112로 전화할까요?`
   - **설명**: `경찰 신고를 위해 112로 연결합니다.`
   - **버튼**:
     - **[ 취소 ]**: 팝업 닫기
     - **[ 전화하기 ]**: `tel:112` 링크로 실제 단말기의 112 전화 걸기 화면 호출
4. **부가 이동 링크**:
   - 관리자 테스트 결제 시: `광고 상태 테스트하기`
   - 공통: `광고내역 보기` (`/account/ads`), `대시보드 이동` (`/?tab=dashboard`)

## 3. 관련 파일
- `app/payments/toss/ad/success/page.js`: 서버 결제 승인 및 클라이언트 컴포넌트 렌더링, 미리보기(`?preview=1`) 지원
- `app/payments/toss/ad/success/ad-payment-success-client.js`: 결제완료 화면 및 112 팝업 인터랙션 클라이언트 컴포넌트
- `public/assets/ads/ad-payment-complete.png`: 사용자 제공 결제완료 그래픽 자산
- `public/assets/ads/police-report-guide.png`: 경찰 신고 연계 버튼 참고 자산
- `public/assets/ads/police-report-call-dialog.png`: 112 팝업 모달 참고 자산
- `app/globals.css`: 결제완료 및 112 모달 반응형 스타일
- `scripts/ad-dashboard-state-regression.mjs`: 결제완료 및 경찰 신고 연계 회귀 테스트
