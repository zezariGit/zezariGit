# 관리자 대상자 QR 수동 활성화

## 목적
- 관리자 수기 테스트를 위해 상품 구매와 결제 없이 특정 관리대상의 QR을 활성화한다.
- 테스트 활성화는 선택한 QR 한 건에만 적용하며 같은 보호자의 다른 관리대상에는 영향을 주지 않는다.

## 관리자 사용 흐름
1. 관리자 화면의 `대상자 관리` 메뉴로 이동한다.
2. 왼쪽 목록에서 관리대상을 선택한다.
3. 오른쪽 상세 현황에서 `QR` 탭을 연다.
4. `구매 없이 QR 수동 활성화` 버튼을 누른다.
5. 하단 완료 메시지와 `활성화 구분: 관리자 테스트` 표시를 확인한다.
6. 테스트가 끝나면 같은 위치의 `수동 활성화 해제` 버튼을 누른다.

## 동작 범위
- QR의 서비스 허용 상태와 활성화 시점을 설정한다.
- 공개 관리대상 페이지 조회, 안심번호 요청, 위치공유를 사용할 수 있다.
- 관리대상 상태는 일반 테스트가 가능하도록 `안전`으로 변경한다.
- 주문, 결제, 구독, 매출 데이터는 생성하거나 변경하지 않는다.
- 정상 구매로 이미 활성화된 QR에는 테스트 활성화를 적용하지 않는다.
- 테스트 해제 시 QR은 `활성화 대기` 상태로 돌아가며 관리대상 상태는 `QR활성화필요`로 변경된다.

## 데이터와 보안
- `qr_codes.activation_source`에 `admin_test` 또는 `guardian_purchase`를 기록한다.
- 관리자 서버 세션을 다시 검증한 뒤에만 실행한다.
- QR 매칭 해제, 다른 대상자 재매칭, 폐기 시 활성화 시점과 출처를 초기화해 테스트 권한이 다른 대상자에게 넘어가지 않게 한다.

## 검증 기준
- 관리자 권한이 없는 요청은 거절된다.
- 미매칭 또는 폐기 QR은 수동 활성화할 수 없다.
- 정상 구매 활성화 QR은 관리자 테스트로 덮어쓸 수 없다.
- 관리자 테스트 활성화 중에는 구독 데이터가 없어도 해당 QR 공개 페이지와 안심번호·위치공유 기능을 사용할 수 있다.
- 해제 후에는 구매 또는 정상 활성화 전까지 공개 정보가 차단된다.
