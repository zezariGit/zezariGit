# REAL_QR_FIND 위치기반서비스 사업계획서 산출물

## 목적

`reference/위치기반서비스 사업계획서(양식).hwpx`의 본문 및 별첨 순서를 기준으로 제자리 QR 안심 위치공유 서비스의 위치기반서비스사업 신고 준비 문서를 작성했다. 원본 양식은 변경하지 않았으며, 현재 소스코드와 운영 산출물에서 확인한 사실만 구현 상태로 기재했다.

## 문서 구성

1. 사업자 현황
2. 서비스 내용과 서비스 시나리오
3. 위치정보 데이터 흐름과 위치정보 제공자 구분
4. 관리적·기술적 보호조치와 현재 구현·보완계획
5. 주요설비와 설치장소
6. 별첨 1 위치정보의 관리지침
7. 별첨 2 기술적 보호조치 증빙자료 목록
8. 별첨 3 사업자 확인서류 목록
9. 제출 전 최종 점검표와 참고 법령

## 재생성 방법

1. Python 의존성 `python-docx`, `Pillow`를 설치한다.
2. `python build_location_service_plan.py`로 DOCX와 구조도를 생성한다.
3. `python build_hwp_html.py`로 한컴 가져오기용 HTML을 생성한다.
4. 한컴오피스가 설치된 Windows에서 `pip install pyhwpx` 후 `python convert_hwp_outputs.py`를 실행한다.
5. 생성된 PDF 전체 페이지를 이미지로 렌더링하여 글자·표·그림 잘림을 확인한다.
6. 원본 Word 양식에 최신 보안 보완서를 다시 합칠 때는 PowerShell 7에서 `pwsh scripts/generate-location-security-doc.ps1`을 실행한다.

## 검증 결과

- HWP: OLE 서명 확인, 한컴오피스 재열기와 주요 5개 섹션 텍스트 확인.
- HWPX: 정상 ZIP 패키지, 본문 XML 1개, 내장 이미지 5개, 주요 섹션과 비밀정보 미포함 확인.
- PDF: A4 19쪽, 모든 페이지 렌더링 후 표·한글·링크·구조도 잘림 없음 확인.
- DOCX: A4 2개 섹션, Heading 1/2/3 사용, 내장 이미지 5개, 모든 표의 `tblW`, `tblInd`, `tblGrid`, `tcW` 일치 확인.
- 민감정보: 환경변수 이름·키·토큰·시크릿 값 미포함 확인.
- 보안 보완본: 원본 46쪽을 보존하고 보완서 7쪽을 추가한 A4 53쪽, 마지막 페이지까지 렌더링 검수.
- 구현 화면: 위치 필드 암호화, 24시간 자동 파기, 단계별 권한, 취급대장, 접근기록, 별도 동의 화면 포함.
