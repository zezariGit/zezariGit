# 상품 결제 배송지·쿠폰 선택 개선

## 목적

- 배송지 기본주소를 카카오 우편번호 검색 결과로만 입력해 임의 수정을 방지한다.
- 상세주소는 사용자가 별도로 입력할 수 있게 유지한다.
- 결제 화면에서 보유 쿠폰 수와 선택 상태를 쉽게 확인하게 한다.
- 모바일 시스템 뒤로가기와 화면 상단 뒤로가기가 쿠폰 선택 및 결제 단계를 순서대로 복원하게 한다.

## 구현 범위

- 결제 배송지의 기본주소 입력은 읽기 전용이며 `주소 검색` 팝업 선택으로만 변경된다.
- 상세주소는 동·호수 등을 직접 입력할 수 있다.
- 쿠폰 영역은 `할인쿠폰`, 사용 가능한 보유 수, 현재 선택 내용을 표시하는 선택 행으로 구성한다.
- 쿠폰 선택 행을 누르면 결제 화면 위에 쿠폰 선택 팝업이 열리고, 쿠폰 사용 안함 또는 사용 가능한 쿠폰을 선택할 수 있다.
- 쿠폰 팝업에서 상단 뒤로가기, 화면 밖 터치, 휴대폰 시스템 뒤로가기를 사용하면 결제 화면으로 복귀한다.
- 결제 단계의 휴대폰 시스템 뒤로가기는 `결제 -> 상품 상세 미리보기 -> 상품 설정` 순서로 이동한다.
- 쿠폰 변경 시 기존 Toss 결제위젯을 중복 생성하지 않고 결제금액만 갱신한다.

## 데이터 처리

- 기본주소와 상세주소는 기존 `shippingAddress`, `shippingAddressDetail` 상태와 주문 준비 API를 그대로 사용한다.
- 쿠폰은 서버에서 전달한 사용 가능 목록만 노출하며 최종 할인액은 주문 준비 API에서 다시 검증한다.

## 검증 기준

- 검색 전에는 기본주소를 키보드로 직접 수정할 수 없어야 한다.
- 주소 검색 완료 후 기본주소에 선택 결과가 표시되고 상세주소로 포커스가 이동해야 한다.
- 쿠폰 팝업을 닫거나 시스템 뒤로가기를 눌러도 `/shop` 결제 화면을 벗어나지 않아야 한다.
- 쿠폰 선택에 따라 주문 요약과 Toss 위젯 금액이 같은 값으로 변경되어야 한다.
- iOS·Android 폭에서 주소 입력과 검색 버튼, 쿠폰 선택 문구가 잘리지 않아야 한다.
