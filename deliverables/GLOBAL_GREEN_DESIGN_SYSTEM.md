# 제자리 공통 초록 디자인 시스템

## 목적

제자리의 사용자 화면과 관리자 화면에서 색상, 서체, 입력창, 버튼, 카드, 상태 표현을 같은 기준으로 유지한다. 모바일 화면을 우선하며 초록색은 주요 행동과 선택 상태 등 강조가 필요한 위치에만 사용한다.

## 확정 색상

| 역할 | HEX | 용도 |
| --- | --- | --- |
| 대표색 | `#26963F` | 주요 버튼, 선택 상태, 핵심 아이콘 |
| 대표 진한색 | `#176B2C` | 버튼 호버, 링크, 강조 텍스트 |
| 대표 연한색 | `#EEF9F0` | 선택 영역과 약한 강조 배경 |
| 대표 테두리 | `#9DCEA8` | 초록 강조 요소의 테두리 |
| 전체 배경 | `#F5F8F5` | 페이지 배경 |
| 기본 표면 | `#FFFFFF` | 카드, 입력창, 팝업 배경 |
| 보조 표면 | `#F1F5F2` | 비강조 정보 영역 |
| 기본 텍스트 | `#17231A` | 제목과 본문 |
| 보조 텍스트 | `#5D6D61` | 설명과 메타 정보 |
| 약한 텍스트 | `#89968C` | 플레이스홀더와 비강조 정보 |
| 성공 | `#15803D` | 성공 문구와 아이콘 |
| 성공 배경 | `#F0FDF4` | 성공 상태 배경 |
| 경고 | `#B45309` | 경고 문구와 아이콘 |
| 경고 배경 | `#FFFBEB` | 경고 상태 배경 |
| 오류 | `#B91C1C` | 오류 문구와 아이콘 |
| 오류 배경 | `#FEF2F2` | 오류 상태 배경 |
| 정보 | `#28663A` | 일반 안내 문구와 아이콘 |
| 정보 배경 | `#EFF7F1` | 일반 안내 상태 배경 |

카카오와 네이버 등 외부 로그인 제공자의 공식 브랜드 버튼 색상은 식별성을 위해 예외로 유지한다.

## 서체와 텍스트

- 기존 확정 서체인 `Noto Sans KR`을 한글과 숫자에 공통 적용한다.
- 사용할 수 없는 환경에서는 `Apple SD Gothic Neo`, `Malgun Gothic`, `sans-serif` 순서로 대체한다.
- 제목, 본문, 설명, 버튼은 전역 크기 토큰을 사용한다.
- 자간은 모든 역할에서 `0`으로 유지한다.
- 사용자에게 표시하는 문구는 화면 컴포넌트가 소유하며 CSS 적용 과정에서 변경하지 않는다.

## 컴포넌트 기준

- 카드와 입력창의 모서리는 `4px` 또는 `8px`를 사용한다.
- 카드 그림자는 `0 1px 2px rgba(23, 35, 26, 0.05)`로 제한한다.
- 팝업처럼 화면 위에 떠야 하는 요소만 `0 8px 24px rgba(23, 35, 26, 0.16)`을 허용한다.
- 입력창, 선택창, 텍스트 영역과 버튼은 같은 서체를 상속한다.
- 키보드 포커스는 `rgba(38, 150, 63, 0.24)`의 3px 외곽선으로 표시한다.
- 비활성 상태는 중립 배경과 문구를 함께 사용하며, 성공·경고·오류 상태는 색상과 문구 또는 아이콘을 함께 표시한다.
- 전체 배경은 밝은 중립색, 카드와 입력창은 흰색을 기본으로 한다.
- 온보딩과 일반 카드의 장식용 그라데이션을 제거하고 얇은 테두리와 충분한 여백으로 구분한다.

## 적용 위치

- `css/gov-style.css`: 공통 디자인 토큰, 기본 서체, 포커스, 카드·표·폼 기준
- `app/globals.css`: 기존 앱 클래스와 공통 토큰의 연결, 로그인·온보딩·대시보드·위치보안·관리자 화면 보정
- `app/layout.js`: 모바일 브라우저 대표 테마 색상 `#26963F`

## 검증 기준

- 모바일 `390 x 844`와 데스크톱 `1440 x 900`에서 화면이 잘리거나 겹치지 않는지 확인한다.
- 페이지 본문과 주요 조작 요소가 표시되는지 확인한다.
- Next.js 오류 오버레이와 브라우저 콘솔 오류가 없는지 확인한다.
- WCAG 2 A/AA 자동 검사 결과를 확인한다.
- 운영 빌드와 보안 회귀 검사를 통과한 변경만 배포한다.
