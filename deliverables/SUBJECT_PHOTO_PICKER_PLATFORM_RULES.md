# 관리대상 사진 선택 메뉴 플랫폼 기준

## 적용 화면

- 관리대상 신규 등록
- 관리대상 정보 수정

두 화면은 공용 `SubjectPhotoInput`을 사용하므로 동일한 기준이 적용된다.

## 표시 옵션

| 환경 | 사진 촬영 앱 | 앨범 앱 | 파일 앱 |
| --- | --- | --- | --- |
| iPhone / iPad / iPod | 표시 | 표시 | 표시 |
| 터치 기반 iPadOS 데스크톱 모드 | 표시 | 표시 | 표시 |
| Android | 표시 | 숨김 | 표시 |
| 일반 웹 브라우저 | 표시 | 숨김 | 표시 |

## 구현 기준

- iOS 계열에서는 `image/*` 앨범 입력을 렌더링한다.
- Android와 일반 웹에서는 앨범 입력 자체를 렌더링하지 않아 메뉴뿐 아니라 숨은 입력도 남지 않는다.
- 촬영 입력의 후면 카메라 요청과 파일 선택기의 이미지 확장자 제한은 기존대로 유지한다.
- 파일 크기 제한, 업로드 미리보기, 필수 사진 검증 로직은 변경하지 않는다.
